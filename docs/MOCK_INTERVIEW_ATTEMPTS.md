# Персональные попытки в «Мок Собесе»

В админке откройте **«Дополнительные попытки мок-собеседований»** в разделе
собеседований, нажмите **«Добавить»**, выберите ученика и укажите количество
дополнительных попыток за 7 дней. Сохраните запись.

Например, общий лимит 3 и дополнительные попытки 2 дают выбранному ученику
5 попыток за последние 7 дней. Остальным ученикам остаётся общий лимит.
Считаются все начатые собеседования, включая прерванные. История не удаляется
и счётчик использованных попыток не сбрасывается.

Прибавка постоянная: действует, пока преподаватель её не изменит. Для возврата
к общему лимиту откройте запись ученика и установите 0. Допустимо от 0 до 100
дополнительных попыток. Если общий лимит изменится, персональная прибавка
сохранится. Общий лимит 0 отключает новые собеседования у всех, даже с прибавкой.

Ученик видит итоговый лимит и остаток на странице начала собеседования.
Персональный лимит проверяется и при запуске на сервере.

Суперпользователь управляет попытками всех учеников. Преподаватель с правами
на этот раздел видит и выбирает только учеников своих групп. После миграции
роли с правом «Может изменять ученика» автоматически получают права просмотра,
добавления и изменения персональных попыток. Право удаления им не выдаётся;
чтобы отменить прибавку, достаточно поставить 0.

## Обновление

Перед применением миграции сделайте обычную резервную копию рабочей базы.
Миграция `interview.0014_mockinterviewallowance` создаёт отдельную таблицу;
старые попытки и общие настройки не изменяет.

```bash
python manage.py migrate
```
